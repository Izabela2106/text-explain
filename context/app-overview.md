# FitX

## Overview

TextExplain is an app that takes user text input and returns this text with explanatory tooltips over key words and hard words or concepts.  

## Goals

1. Let user to paste text and return text with explained key words and concepts

## Core User Flow

1. User enters the page
2. User pastes an text
3. User clicks explain button.
4. AI analyzes the text and return text with expalatory tooltips and word underlying

### URL form

- Input for text
- button that starts generating output
- place for returned text


## Success Criteria

1. AI can generate user text with tooltips what explain words and concepts
